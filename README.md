## 🎯 What is Finora?

**Finora is the budget app your therapist wishes you'd use.**

Forget boring spreadsheets. Finora is your **AI bestie** who:
- 🗣️ **Talks like your friend** (because "you spent $836.50 this month" hits different than "expenditure analysis complete")
- 📸 **Sees what you're about to buy** and tells you if it's a vibe or financial suicide
- ⚖️ **Debates with itself** (Angel vs Devil) before you impulse-buy that jacket
- 💰 **Tracks your spending** by just talking to it like you're texting
- 🎉 **Celebrates wins** with confetti when you save money (dopamine matters, fr)

### The Problem We're Solving

**70% of college students experience financial stress.** Traditional budget apps fail because they're:
- ❌ Designed for adults with stable income
- ❌ Cold, corporate, and judgmental ("You overspent by $127.43" - thanks, Dad)
- ❌ Full of forms and charts nobody has time for
- ❌ One-way tools with zero emotional support

**Students need a friend who gets it, not another spreadsheet.**

## 🚀 Quick Start

### Prerequisites

- **Node.js 18+** and npm
- **Supabase account** (free tier works)
- **Anthropic API key** ([Get one here](https://console.anthropic.com/))
- **ElevenLabs API key** ([Get one here](https://elevenlabs.io/))

### Installation (5 minutes)

```bash
# 1. Clone the repo
git clone https://github.com/CarlGergi/anthropichackaton.git
cd anthropichackaton

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Edit .env with your Supabase URL and key

# 4. Deploy Edge Functions
supabase login
supabase link --project-ref your_project_ref
supabase secrets set ANTHROPIC_API_KEY=sk-ant-your-key
supabase secrets set ELEVENLABS_API_KEY=your-key

# Deploy all functions
supabase functions deploy claude-intent
supabase functions deploy claude-vision
supabase functions deploy finora-debates
supabase functions deploy elevenlabs-tts

# 5. Run the app
npm run dev
```

Open **http://localhost:5173** and start talking to Finora! 🎤

> **Note:** Use **Chrome or Edge** for best compatibility (Safari/Firefox don't support Web Speech API)

## 🧠 How It Works

### Conversation Flow

```mermaid
graph LR
    A[User Speaks] --> B[Web Speech API]
    B --> C[Claude Intent]
    C --> D[AI Response]
    D --> E[ElevenLabs TTS]
    E --> F[Finora Speaks]
    F --> G[State Updated]
```

1. **User speaks** → Web Speech API captures audio
2. **Text sent to Claude** → `claude-intent` Edge Function
3. **Claude analyzes** → Intent recognition + Gen Z response
4. **Response includes:**
   - Natural speech (15-25 seconds)
   - Recommendations (if low on money)
   - Analysis (if requested)
   - State updates (budget/transactions)
5. **Speech generated** → ElevenLabs converts to audio
6. **Finora speaks** → Audio plays with animated character
7. **State saved** → LocalStorage for privacy

### Vision Flow

```
📸 Take photo → 🔄 Encode base64 → 🚀 Claude Vision API
→ 🧠 AI analyzes (OCR + understanding) → 📊 Affordability calc
→ 💬 Gen Z advice → ✅ Display results → 📝 Optional logging
```

**What Claude Vision does:**
- Identifies image type (menu, receipt, price tag, shopping cart)
- Extracts items with prices using OCR + AI understanding
- Calculates affordability based on your remaining budget
- Generates personalized Gen Z advice
- Suggests cheaper alternatives
- Provides one-click logging for receipts

### Debate Flow

```
💭 Question asked → 📊 Budget context calculated
→ 🔥 3 parallel Claude calls:
   ├── Devil (emotional, temp 1.0)
   ├── Angel (logical, temp 0.8)
   └── Verdict (balanced, temp 0.7)
→ 🎭 Responses merged → 📱 Display side-by-side
→ 🤔 User decides with full info
```

## 🚨 Troubleshooting

<details>
<summary><b>White screen / App won't load</b></summary>

- Open browser console (F12) for errors
- Verify `.env` file exists with correct Supabase URL and key
- Check Supabase project is active
- Clear browser cache and reload
</details>

<details>
<summary><b>Can't hear Finora speaking</b></summary>

- Deploy Edge Functions: `supabase functions deploy elevenlabs-tts`
- Verify secrets: `supabase secrets list`
- Check ELEVENLABS_API_KEY is set correctly
- Ensure browser audio isn't muted
- Check Supabase Edge Functions logs for errors
</details>

<details>
<summary><b>Microphone not working</b></summary>

- **Use Chrome or Edge** (Safari/Firefox don't support Web Speech API)
- Grant microphone permissions when prompted
- Check browser settings → Site permissions
- HTTPS required in production (localhost works in dev)
</details>

<details>
<summary><b>Camera / Vision not working</b></summary>

- Grant camera permissions when prompted
- Deploy `claude-vision` function
- Verify ANTHROPIC_API_KEY includes Vision access
- Ensure image size < 5MB
- HTTPS required in production
</details>

<details>
<summary><b>Debates not loading</b></summary>

- Deploy `finora-debates` function
- Verify ANTHROPIC_API_KEY is set as secret
- Ensure question includes a price (e.g., "Should I buy that **$80** jacket?")
- Check Supabase Edge Functions logs
</details>

<details>
<summary><b>Edge Functions failing</b></summary>

- Check Supabase Dashboard → Edge Functions → Logs
- Verify API keys are set as **secrets** (not in .env)
- Ensure Anthropic API key starts with `sk-ant-`
- Check deployment: `supabase functions list`
- Try redeploying: `supabase functions deploy function-name`
</details>
